# 03. 상위 1개짜리 모부품 박스가 지워져 BOM을 못 고름 (2026-11-18)

## 증상
BOM 고르기(연결선 수 = 모부품 박스 행 수, [03 3-1절](../설계/03_표_찾기.md))가 샘플 820개 중 **779개만 성공**. 실패 41개는 전부 상위 품번이 1개인 도면.

## 원인
① 후보 거르기의 길이 기준이 19 (BOM 행 높이 19.8만 보고 정함). 모부품 박스 1칸의 세로변은 **18.4**라 글자로 보고 지워짐 → 박스가 없어 행 수를 못 셈.
- case_0004: 박스 세로변 x 585.4·693.1, y 136.0→154.5 (길이 18.4)
- 상위가 2개 이상이면 세로변이 36.8 이상이라 살아남음

## 선 길이 확인
| 선 | 길이 | 확인 |
|---|---|---|
| 보통 글자 획 | 99%가 9.2 이하 | 샘플·테스트 |
| 가장 긴 글자 획 | 샘플 12 미만 / 테스트 13.2~14.2 (큰 글씨, 6개 모두) | 글자 덩어리 path 안 획 |
| 테두리 겹 사이 눈금선 | 14.2 | case_0001 y 28.4→42.5 |
| 짧은 가로선 | 15.6 | case_0001 BOM·모부품 박스 왼쪽 옆. 리비전 삼각형 밑변으로 보임 (미확인) |
| 모부품 박스 1칸 세로변 | **18.4** | case_0004 |
| BOM 행 높이 | 19.8 | case_0001 |

## 해결 후보
| 기준 | BOM 고르기 (샘플) | case_0001 후보 / 묶음 | 판단 |
|---|---|---|---|
| 19 | 779/820 | 135 / 22 | ✗ 박스가 지워짐 |
| 18 | 820/820 | 135 / 22 | ✗ 박스와 여유 0.4 |
| 16 | 820/820 | 135 / 22 | 글자는 깔끔히 지움, 박스와 여유 2.4 |
| **14** | **820/820** | 150 / 33 | ✓ 박스와 여유 4.4. 큰 글씨 획(14.2) 일부가 남음 |

## 결정: 14
두 실수의 비용이 다르다. 글자 획이 남으면 뒤 단계(BOM 고르기)에서 걸러지지만, 표 선을 지우면 되살릴 수 없다 → 앞 단계는 **놓치지 않는 쪽(재현율 우선)**.
- 대가: 후보가 늘어 묶기가 느려짐 (88500 후보 3901 → 5687, 묶기는 n²)
- 남은 획이 BOM 선에 닿으면 BOM 묶음에 섞일 수 있음 → 칸 나누기는 표 전체를 가로지르는 선만 경계로 쓴다 (취소선과 같은 문제)
- 변수는 도면 크기가 아니라 **글자 크기** (큰 도면 case_0102도 행 높이 19.8). 글자가 훨씬 큰 도면이 나오면 도면마다 글자 크기를 재서 기준을 정하는 방식으로 바꾼다

- 기준값을 정할 때 "지울 것"(글자)뿐 아니라 "남길 것" 중 가장 짧은 것(박스 1칸)도 재야 한다
- 거르는 단계는 넓게, 확정은 뒤 단계에서
