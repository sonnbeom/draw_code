# 05. 테스트 도면: 살짝 기운 연결선을 못 알아봄 (2026-11-18)

## 증상
화살촉 합치기([04](04_화살촉_틈.md)) 뒤에도 88361만 BOM 고르기 실패. 연결선 3개만 잡히고 박스 행은 4개 → 3 ≠ 4.

## 원인
연결선 4개 중 하나가 아주 살짝 기울어 있다 (약 1.1°, 눈으로 안 보임).
```
 상위 박스 세로변 x 1522.8
   ├──────────────────────● (1571.14, 1030.46)   ← 가로 부분이 꺾이는 점 (위 끝)
                           \
                            ● (1570.59, 1059.35)  ← 화살촉 꼭짓점까지 늘린 끝 (아래 끝)
 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  BOM 윗변 y 1059.4
```
막히는 곳이 두 군데:
| 곳 | 지금 코드 | 이 선 |
|---|---|---|
| ① 거르기 `is_vertical` | `abs(x1 - x2) <= 0.5`면 세로선 | 합치기 전 0.39 (겨우 통과) → 늘린 뒤 **0.55** → 세로선 아님, 지워짐 |
| `select_bom` `_find_leg` | 꺾이는 가로선 끝 x == `drop.x1` (세로선의 x는 하나라고 가정) | `drop.x1`은 아래 끝 1570.59, 가로선은 위 끝 1571.14에 닿음 → 0.55 차이 → 못 찾음 |

## 기울기 분포 (길이 14 이상, 가장 가까운 축에서 벗어난 각도)
| 각도 | 샘플 100개 | 테스트 6개 |
|---|---|---|
| 0° | 26,213 | 12,865 |
| 0.05~1° | 0 | 974 |
| 1~5° | 0 | 1,296 (88361 연결선 1.1°) |
| 5~10° | 11 | 947 |
| 10~45° | 1,954 | 5,912 (일부러 그은 사선: 풍선 지시선 확인, 해칭·곡선 조각 추정) |

- 샘플(프로그램 생성)은 0° 아니면 5° 이상. 테스트(엔지니어 도면)는 0~10°가 끊김 없이 이어짐
- 테스트 도면 그리기 명령은 직선 `l`·사각형 `qu`뿐, 곡선 0개 → 곡선도 짧은 직선 조각
- 길이 29 선 기준 끝 벌어짐: 1.1° → 0.55 (안 보임), 3° → 1.5, 10° → 5.1 (눈에 띄는 사선)

## 해결 후보
| 후보 | 해결되는 곳 | 판단 |
|---|---|---|
| 1. 세로·가로 판정을 **각도로** ("3° 이하") | ① 거르기 | ✓ 길이와 상관없이 같은 기준. 사람이 그린 도면은 100% 똑바르지 않다 |
| 2. x 값 하나 대신 **위 끝·아래 끝 점**으로 닿았는지 확인 (`point_on_line`) | `select_bom` | ✓ 선이 기울어도 꺾이는 곳에서는 끝점이 같은 점 |
| 3. 살짝 기운 선을 똑바로 펴기 (x를 평균으로) | 둘 다 | ✗ 끝점이 움직여 원래 닿던 선과 떨어질 수 있음 (위 예 0.27 이동) |

|---|---|---|
| 1° | ✗ | 약 970 |
| 2° | ✓ | 약 1,150 |

## 결정
**1 + 2, 허용 각도 3°.** 판정은 "손 떨림" 수준으로 느슨하게, 대신 끝점이 실제로 이어져야 꺾은 선(연결선)으로 인정.
- `bom/geometry.py`: `is_horizontal`·`is_vertical`을 기울기 3° 이하로
- `bom/select_bom.py`: `drop.x1`·`ln.y1`처럼 한 좌표로 대표하지 않고 선의 위 끝·아래 끝 점을 따로 써서 `point_on_line`으로 확인
