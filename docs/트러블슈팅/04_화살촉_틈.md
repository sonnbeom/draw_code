# 04. 테스트 도면: 화살촉 때문에 연결선이 BOM에 안 닿음 (2026-11-18)

## 증상
BOM 고르기를 테스트 도면 6개에 돌리니 22000·88300만 성공. 상위가 박스인 28440·88361·88400이 실패 (88500은 상위가 표라 별도).

## 원인
테스트 도면은 연결선 끝에 **화살촉**이 있다. 세로선은 화살촉 밑변에서 끝나고, 화살촉 꼭짓점이 BOM 윗변에 닿는다.
```
      │  세로선: y 1528.69 → 1557.12 에서 끝남       (28440)
     ─┴─  화살촉 밑변 (2767.65~2770.50, 1557.12)
      ▼   화살촉 (선 3개 삼각형)
  ━━━━━━━  BOM 윗변 y 1565.62 = 꼭짓점     ← 세로선 끝과 8.5 틈
```
- 88400 (1496.0 → 1504.5), 88361 (1050.9 → 1059.4)도 같은 8.5 틈
- 화살촉 선은 짧은 사선이라 ① 거르기에서 지워짐 → 세로선이 BOM에 안 닿음 → ③ 묶기에서 BOM과 연결선이 **다른 묶음** → 어느 묶음에도 "연결선이 꽂힌 표"가 없음
- 샘플은 화살촉 없이 연결선이 윗변까지 내려옴 (칠한 도형 0개)

## 화살촉 정의 후보
| 후보 | 결과 |
|---|---|
| 크기 (2.8×8.5) | ✗ 도면마다 다름 (88500 2.9×5.5) |
| 이등변·뒤집힌 모양 | ✗ 다른 도면에서 이등변이 아닐 수 있음 |
| 칠한 도형(`f`) | 안 씀. 같은 화살촉을 칠하기 + 선으로 두 번 그리기도 함 |
| 선 3개 삼각형 + 표에 닿음 | ✗ 리비전 삼각형도 선 3개이고 표에 닿음 (28440 30개 이상). 또 이 시점엔 표를 아직 모름 |
| 선 3개 삼각형 + 변 30~70%에 선 끝이 닿음 | 정삼각형류 오검출 10개 (22000 2·88400 8: 변 가운데에서 비스듬히 빠지는 지시선, 예 (3584.6, 1709.0)→(3571.6, 1731.6)) |
| **+ 그 선이 반대쪽 꼭짓점을 향함** | ✓ 정삼각형류 오검출 0, 연결선 화살촉 28440 2/2·88361 4/4·88400 8/8 |

## 결정
화살촉 = 아래를 모두 만족 (크기·모양·칠하기 안 씀, 연결 관계만)
1. 선 3개로 닫힌 삼각형 (같은 좌표로 두 번 그린 것은 하나로)
2. 삼각형 **바깥**에서 온 선의 끝이 한 변(= 밑변)의 **30~70% 구간**에 닿음 (오차 0.5)
3. 그 선을 연장하면 **밑변 반대쪽 꼭짓점을 향함** (방향 차이 약 8° 이내)

합치기: 그 선의 끝을 꼭짓점까지 늘린다. **① 거르기 전에** 한다 (`bom/arrows.py`).
- 후보는 넓게: 치수선·지시선 화살촉도 늘어나지만 원래 가리키던 곳까지라 무해 (22000 늘어난 선 약 290개)
- **확정은 BOM 고르기에서**: 늘어난 선 중 꼭짓점이 BOM 윗변에 닿은 것만 연결선으로 센다. 후보를 별도 목록으로만 두면 ③ 묶기에서 틈이 남아 BOM과 연결선이 갈라지므로 늘린 선으로 남긴다
- 속도: 88500은 선 약 65만·삼각형 약 4,300 → 삼각형마다 전체 선을 훑지 말고 좌표 칸으로 근처 선만 본다 (88500 합치기 3.4초)
