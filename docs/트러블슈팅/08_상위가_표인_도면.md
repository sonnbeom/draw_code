# 08. 88500: 상위가 표인 도면에서 BOM을 못 고름 (2026-11-23)

## 증상
테스트 도면 88500에서 `select_bom`이 None. 상위 표와 하위 BOM은 한 묶음(선 155개)으로 잘 묶였고 하위 BOM 윗변(y 743.55)도 찾았지만, **연결선 2개 / 상위 행 26개**로 "연결선 수 = 행 수"에 걸림 (정답 25 = 25).

## 원인
**1. 화살표 꼭짓점이 윗변에 안 닿음 (연결선 25개 중 23개)**
```
drop     (4450.85, 703.11) → (4450.85, 740.67)   아래 끝 y 740.67
화살촉   (4450.11, 735.05) → (4450.85, 740.67)   선 2개짜리 열린 V, 꼭짓점 = drop 아래 끝
         (4450.85, 740.67) → (4451.59, 735.05)
BOM 윗변 y 743.55   → 틈 2.88
```
- 기존 조건은 drop 아래 끝이 윗변 위(오차 0.5)여야 함
- 찾은 2개는 맨 위 두 행의 기울어진 선(docs/13)으로, 이 둘만 꼭짓점이 743.55에 닿음
- [트러블슈팅 04](04_화살촉_틈.md)(닫힌 삼각형 때문에 선이 짧음)와 다름. 이번엔 꼭짓점 자체가 윗변에서 떨어져 있음

**2. 상위 표에 머리글 행이 있음**
- 상위 표 세로변 x 4406.0 (y 88.7~715.2)에 닿는 가로선 경계 27개 → 26행
- 맨 위 88.7~112.8은 머리글(`I/NO | PART NO | PART NAME | NOTE`), 연결선 없음. 품번 행은 25개
- 샘플 모부품 박스는 머리글이 없어 지금까지 행 수 = 연결선 수가 맞았음

## 해결 후보
| 문제 | 후보 | 판단 |
|---|---|---|
| 틈 | A. 모든 세로선에 허용 거리를 늘림 | △ 근처의 다른 세로선이 섞일 수 있다는 걱정 |
| | B. 열린 V 화살촉을 찾아 선을 늘림 (트러블슈팅 04 방식) | △ 늘려도 꼭짓점까지라 틈은 그대로 |
| | **C. drop 아래 끝이 윗변보다 6 이내 위면 허용, leg·박스 세로변 조건은 그대로 엄격** | ✓ 엔지니어가 그린 연결선 모양(leg + drop + 박스 세로변)이 다 있을 때만 봐주는 셈. 6 = 화살촉 길이 약 5.6 |
| 출발점 쪽도? | 출발점(leg ↔ 상위 세로변)도 틈 허용 | ✗ 실제 도면 연결선 41개(1+2+1+4+8+25) 전부 0.5 안에서 맞닿음, 틈은 끝점(화살표) 쪽만 나옴. 양쪽을 다 풀면 다른 가로선이 leg로 잡힐 위험. 떨어진 도면이 나오면 그때 재서 넣음 |
| 머리글 | A. 연결선이 나가는 행만 셈 | ✗ 그러면 연결선 수 = 행 수가 항상 같아져 BOM 판정 의미가 없음 |
| | B. OCR로 머리글 글자 확인 | ✗ OCR은 5단계, BOM 고르기는 2단계 |
| | **C. 연결선마다 출발 행 번호(`find_slot`)를 정하고, 행마다 1개 + 빈 행은 맨 위 행만 허용** | ✓ 위치만으로 판정. 중간 행이 비거나 한 행에서 2개 나가면 BOM 아님 |

## 결정
틈 C + 머리글 C. `find_slot`은 `select_bom`과 `connect`가 같이 쓰므로 `geometry.py`로 옮김 (순환 import 방지).

## 결과
- `check_test_drawings`: 22000 1 · 28440 2 · 88300 1 · 88361 4 · 88400 8 · **88500 25**, 30.4초
- `check_select_bom` 820/820 유지 (55.0초), `check_connect` 819/820 유지
- 88500 연결 추적: 상위 행 1~25(0 = 머리글) → 열 28~4, QT'Y 병합 칸 col 4·폭 25. 위 행일수록 오른쪽 열, docs/13 실측(1번째 행 → 25열, 25번째 → 1열)과 같음

## 한계
- 선만으로는 맨 위 행에 연결선이 없을 때 **머리글인지, 품번 행인데 연결선을 놓쳤는지** 구분 못 함. 88500 머리글 행 높이(88.7~112.8, 24.1)도 다른 행과 같음
- 영향은 BOM 고르기가 아니라 **상위 품번 수가 1개 모자랄 수 있는 것**뿐 (맨 위 행에서만, 중간 행이 비면 BOM 아님으로 걸러짐)
- 샘플은 박스에 머리글이 없어 놓치면 `num_parents`와 달라져 `check_select_bom`에 걸림
- 확정은 5-2 머리글 OCR: 맨 위 행 글자가 머리글 단어면 정상, 품번이면 "연결선 놓침" 경고

## 교훈
- 허용 오차는 "선 하나"가 아니라 **모양 전체가 갖춰졌는지**를 조건으로 걸면 넓혀도 안전하다
- 앞 단계 판정은 뒤 단계(OCR) 결과에 기대지 않는다. 위치 정보로 풀 수 있는지 먼저 본다
