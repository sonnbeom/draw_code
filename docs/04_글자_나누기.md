# 3. 글자 나누기 (Q9~11)

> 앞 단계와의 연결: 셀(칸) 위치를 알았다 → 칸 안에는 선 수십 개가 있다. 이걸 글자 단위로 나눠야 읽을 수 있다.

## Q9. 칸 안의 선 수십 개를 글자 하나씩 나누려면?

**내 답.** 같은 글자의 선은 연결되어 있고, 다음 글자와는 연결되어 있지 않다.

**정리.**
- **연결 요소(connected components)**: 이어진 선끼리 한 묶음 → 묶음 하나 = 글자 하나
- 글자 하나씩 나누면 "0~9, A~Z, - 중 무엇?"을 고르는 **분류 문제**가 된다. 칸 전체를 한 번에 읽는 것보다 훨씬 쉽다.

## Q10~11. 떨어진 조각으로 된 글자는? 글자가 붙어 있으면?

`:` `=` `i`처럼 떨어진 조각으로 된 글자는? case_0001처럼 글자가 붙어 있으면 "가깝다"를 어떻게 정하지?

**내 답.**
- (처음) x범위를 보면 가깝다. "가깝다"는 말이 추상적이지만 옆 글자와는 거리가 있다. 그런데 case_0001은 글자가 굉장히 붙어 있는데 x범위를 어떻게 하지?
- (다음) 떨어져 있거나, 아예 x범위 안에 들어 있다. ':'는 x범위가 이어져 있다. 띄어쓰기를 하면 새 x블록이 생긴다.

**정리.**
- x범위가 **겹치면** → 같은 글자 / **떨어져 있으면** → 다른 글자 / 틈이 유난히 크면 → 띄어쓰기
- "얼마나 가까운가"라는 숫자 기준이 필요 없다. 글자가 붙어 있어도, 도면 크기가 달라도 동작한다.
- 예외: `"`처럼 두 획이 옆으로 나란히 있는 글자는 쪼개질 수 있다 → 구현할 때 데이터로 확인
