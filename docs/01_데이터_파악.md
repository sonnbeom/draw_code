# 0. 데이터 파악 (Claude가 조사한 사실)

> 설계를 시작하기 전에 샘플 데이터가 어떻게 생겼는지 확인한 내용.

- xlsx 1000개, PDF 820개 (0821~1000은 PDF 없음) → **학습에 쓸 수 있는 건 820쌍**
- `ground_truth_1000.json` = xlsx와 같은 정답을 구조화한 것 (모부품, rev, 행별 DEL/BLUE, 모부품별 수량)
- xlsx 구조
  - 1행: `NO | PART NO | PART NAME | [1] 32100-TMC00A (03) | ...` (모부품 번호·품번·rev)
  - 2행: 모부품 이름
  - 3행~: 부품 행 (번호, 품번, 품명, 모부품별 수량)
  - 표시: `13 (04) [DEL]` = 취소선 + rev 04 / `[BLUE]` = 파란 행 / `(02,01)` = 삼각형 2개
- PDF에 들어 있는 것
  - 부품표(BOM), 그 위에 쌓인 **모부품 박스**, 박스에서 수량 열로 내려오는 **화살표 연결선**
  - 파란 삼각형(△) 안의 숫자 = rev
- 어려운 점
  - 헤더 스타일 3종: standard / slash_pno (I/NO, P/NO) / slash_qty_assy (대각선 Q'TY·ASS'Y)
  - 모부품 1~8개, 부품 4~24행, 품명이 두 줄로 넘어가기도 함
  - 페이지 크기 30종 (A3 1190×842 ~ 초광폭 11905×2384). case_0306은 긴 도면 구석에 표가 작게 있음
- 색: 검정 `0 0 0`, 파랑 `0 0.314 1` (rev 삼각형, BLUE 행), `0 0.353 0.706` (로고, 치수선)
