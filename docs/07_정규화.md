# 6. 정규화 (Q16~17)

> 앞 단계와의 연결: 취소선을 빼고 글자 묶음을 얻었다 → 그런데 같은 글자가 도면마다 위치·크기가 다르다.

## Q16~17. 같은 '8'인데 도면마다 좌표가 다르다

같은 '8'인데 도면마다 좌표가 다르다 (438~441 vs 9800~9812). 어떻게 같은 입력으로 만들까?

**내 답.**
- (처음) 취소선을 빼고 글자로 학습하자는 거지? 배율 조절?
- (다음) 줄이면 잘리고 늘리면 글자가 이상해진다는 말인가? 같은 비율로 늘리면 되지 않나?

> 막혔던 지점: "위치 차이가 무슨 말이냐 (표 안에서 선으로 처리하는데)", "(0,0)으로 옮기는 이유가 뭐냐"

**정리.**
- PDF 좌표는 **종이 전체 기준**이다 (왼쪽 아래 구석 = (0,0)). 같은 표 안에서도 행·칸마다 같은 '8'의 좌표가 다르다.
- 모델은 숫자만 보니까, 위치가 다르면 다른 것으로 배운다. 처음 보는 위치(새 도면)에서 못 알아볼 수 있다.
  - 이 이유는 [09_모델_선택.md](09_모델_선택.md) Q22에서 숫자로 다시 확인했다 (옮겨진 "1"의 거리 = 7)
- 글자의 정체는 **선들의 상대적인 배치**다 → 위치를 없애고 모양만 남긴다. (0,0)인 이유는 그냥 가장 단순한 공통 기준점이기 때문이다.
- 가로·세로를 따로 늘리면 찌그러진다 ('-'가 꽉 찬 네모가 됨) → **같은 비율로**
- 글자마다 자기 크기로 키우면 '.'와 'O', ','와 '''를 구분할 수 없게 된다 → **같은 줄의 글자 높이**를 기준으로
- 최종 기준
  - **x**: 각 글자의 왼쪽 끝 = 0
  - **y**: 그 **줄의 바닥** = 0
  - **배율**: 줄의 글자 높이로 나눔 (가로세로 같은 비율)
