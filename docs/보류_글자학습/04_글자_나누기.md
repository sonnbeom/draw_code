# 04. 글자 나누기

## 문제
칸 안에는 선 수십 개가 있다. 읽으려면 글자 하나 단위로 나눠야 한다.

## 결정 1. 이어진 선끼리 묶는다
- **연결 요소(connected components)**: 이어진 선끼리 한 묶음 = 글자 하나
- 글자 하나씩 나누면 "0~9, A~Z, - 중 무엇?"을 고르는 **분류 문제**가 된다. 칸 전체를 한 번에 읽는 것보다 훨씬 쉽다

## 문제 2. 떨어진 조각 글자(`:` `=` `i`), 서로 붙어 있는 글자(case_0001)

| 후보 | 장점 | 단점 |
|---|---|---|
| 거리 기준 ("가까우면 같은 글자") | 단순 | 기준 숫자를 정해야 함, 도면 크기·글자 간격마다 다름 |
| **x범위 겹침** | 숫자 기준 불필요, 붙은 글자·도면 크기와 무관 | `"`처럼 두 획이 나란한 글자는 쪼개질 수 있음 |

**결정.** x범위 겹침
- 겹치면 → 같은 글자 / 떨어져 있으면 → 다른 글자 / 틈이 유난히 크면 → 띄어쓰기
- `"` 같은 예외는 구현 때 데이터로 확인
