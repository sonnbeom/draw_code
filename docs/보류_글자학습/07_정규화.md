# 07. 정규화

## 문제
같은 '8'인데 도면마다 좌표가 다르다 (x 438~441 vs 9800~9812). PDF 좌표는 **종이 전체 기준**(왼쪽 아래 = (0,0))이라 같은 표 안에서도 칸마다 다르다. 모델은 숫자만 보므로 위치·크기가 다르면 다른 글자로 배운다.

글자의 정체는 **선들의 상대적인 배치**다 → 위치·크기를 없애고 모양만 남긴다.

## 결정 1. 위치: 기준점을 빼서 0으로
- **x**: 각 글자의 왼쪽 끝 = 0
- **y**: 그 **줄의 바닥** = 0 (글자 자기 바닥이 아님 → "-"가 바닥으로 내려가 "_"처럼 되는 것을 막음)
- 0인 이유: 가장 단순한 공통 기준점일 뿐. "기준점을 뺀다"의 결과가 0
- 위치를 안 맞추면 생기는 일 (0/1 격자에서 다른 칸 수 비교): [09_모델_선택.md](09_모델_선택.md)의 거리 예시

## 결정 2. 크기: 나누는 기준

| 후보 | 문제 |
|---|---|
| 가로·세로 따로 늘림 | 찌그러짐 ('-'가 꽉 찬 네모가 됨) |
| 글자마다 자기 크기로 | '.'와 'O', ','와 '''를 구분 못 함 |
| **같은 줄의 글자 높이로, 가로세로 같은 비율** | - |

**결정.** 줄 높이로 나눈다 (가로세로 같은 비율)
- 줄 바닥·높이는 **행 전체**로 정한다 ("-"만 있는 칸 문제, [11_데이터_품질.md](11_데이터_품질.md))

## 식: 최소-최대 정규화 (min-max normalization)
```
(값 − 기준점) / 길이        빼기 = 위치 맞춤, 나누기 = 크기 맞춤
예: 발 200, 머리 360 (키 160), 손 280 → (280 − 200) / 160 = 0.5
    어디 서 있든, 키가 얼마든 손은 몸의 50%
```
