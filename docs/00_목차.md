## 전체 흐름
```
PDF → ① 선 추출 → ② 표 찾기 → ③ 칸 나누기 → ④ 규칙 처리 → ⑤ 글자 읽기 → ⑥ 조립 → ⑦ xlsx
      (좌표+색)   (연결선으로   (격자→칸)    (취소선·삼각형  (줄→글자→정규화  (행·모부품)
                   BOM 판별)                 ·연결선 지움)   →16×16→선형 모델)
학습: train PDF → 자동 라벨링(개수·크기 검사로 버림) → k-NN 점검 + 선형 모델
평가: test PDF → 행 정확도(주) / 칸 / 글자, 단계별 원인 가르기
```
