## 전체 흐름
```
PDF → ① 선 추출 → ② 표 찾기 → ③ 칸 나누기 → ④ 연결 추적 → ⑤ 규칙 처리 → ⑥ 글자 읽기 → ⑦ 조립·검사 → ⑧ xlsx
      (좌표+색)   (격자+머리글   (격자→칸)    (끝점 따라   (취소선·삼각형  (OCR)        (신뢰도·경고)
                   OCR+연결선)                 수량 열로)   ·연결선 지움)
ML: 칸 신뢰도 (틀렸을 확률 → 검수 표시), 표 종류 분류 (종류가 늘면)
평가: test PDF → 행 정확도(주) / 칸 / 글자, 단계별 원인 가르기
```
