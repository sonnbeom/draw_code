## 지금까지의 전체 흐름

```
PDF
 └─ 선 목록 (좌표 + 색)
     ├─ [기하 규칙] 표 선 후보 → 격자 → BOM 표 판별 → 모부품↔수량 열 매핑 → 셀 위치
     ├─ [기하 규칙] 취소선 → DEL 기록 후 제거
     └─ [머신러닝] 셀 안의 선 → 글자 묶기 → 정규화 → 16×16 격자 → 분류 모델 → 글자
                   (학습 데이터: json 정답으로 자동 라벨링, 개수 안 맞으면 버림)
                   (모델: k-NN 베이스라인 → 선형 모델 → MLP, PDF 단위 train/val/test)
```

## 고민의 흐름 한 줄 요약
1. 글자가 텍스트가 아니라 **선**이다 → 읽으려면 머신러닝이 필요하다
2. 이미지로 바꾸면 표 구조가 사라진다 → **선 좌표**를 그대로 쓰자
3. 표는 **기하 규칙**(길고 수평/수직, 끝점 맞닿음, 모부품 연결선)으로 찾는다
4. 글자는 **연결 요소 + x범위**로 나눈다
5. 정답은 json에 있으니 **자동 라벨링**, 안 맞으면 버린다
6. 취소선은 규칙으로 찾아 DEL 기록 후 지운다
7. 같은 글자가 같은 숫자가 되도록 **정규화**, 개수를 맞추려고 **래스터화**
8. 숫자 256개를 비교하는 **거리**에서 출발해 k-NN → 가중치 학습까지
