# 17. 칸 나누기 (2단계 마지막, `bom/cells/split_cells.py`)

> 앞 단계: [03](03_표_찾기.md) BOM 고르기 → 이 문서 → 다음: 연결 추적 ([13](13_모부품_박스.md))

## 문제 정의
- BOM 고르기가 돌려주는 건 "BOM을 이루는 선분 목록"뿐이다. 행·열을 모른다
- OCR은 **글자 + 위치**만 준다. 글자를 xlsx의 (행, 열)에 넣으려면 칸 위치 목록이 필요하다 (OCR을 칸 단위로 하든 표 전체로 하든 똑같이 필요)
- 연결 추적(3단계)은 "연결선 끝 x → 몇 번째 수량 열"을, 규칙 처리(4단계)는 "취소선 → 몇 번째 행"을 칸 경계로 정한다

```
OCR  → 내용 (무엇이 적혔나: 글자 + 위치)
선   → 구조 (칸 범위, 수량 열 ↔ 상위 품번, DEL·rev)
조립 → 글자 위치가 칸 범위 안에 있으면 그 칸 (공간 매칭)
```

## 1. 행 경계: 취소선을 어떻게 빼나
샘플 BOM 묶음(`select_bom`의 `match.lines`)에는 행 경계와 같은 길이의 **취소선**이 섞여 있다 ([06](06_취소선.md)).

| 후보 | 방법 | 판단 |
|---|---|---|
| A. 길이 | 표 폭 전체인 가로선만 경계 | 실제 도면의 짧은 취소선은 빠짐. 샘플 취소선은 폭 전체라 **못 뺌** |
| B. 간격 중앙값 | y 간격 목록의 중앙값을 "정상 행 높이"로 보고, 절반 간격인 선을 뺌 | 취소 행이 많으면 깨짐: case_0001은 6행 중 3행 취소 → 반쪽 간격 6개 > 정상 3개 → 중앙값이 반쪽(약 10) |
| B'. 간격 종류의 가운데 | 간격을 종류(머리글·정상·반쪽)로 묶어 가운데 | 머리글 높이·두 줄 행 등 표 모양에 따라 규칙이 늘어남 |
| **C. 글자 획이 가로지름** | 획의 위 끝 < 선 y < 아래 끝이면 취소선 | **선 하나만 보고** 판정. 취소 비율·머리글 모양과 무관. 4단계 DEL 찾기와 같은 판정 |

**결정: A + C.** 꽉 찬 가로선(A) 중 글자 획이 가로지르지 않는 선(C)의 y = 행 경계.
- 글자 획 = 표 범위 안의 길이 14 미만 선 (`MIN_TABLE_LINE`, ①에서 거른 기준)
- 선에 닿기만 한 획은 제외 (위·아래 모두 `TOUCH_TOL` 넘게 벗어나야 가로지름)
- 꽉 찬 가로선 계산은 `select_bom.find_top`과 같아서 `full_width_lines`로 빼서 같이 쓴다

## 2. 열 경계: 하위 BOM 세로선 알아보기
BOM 묶음에는 상위 박스 세로변과 연결선 `drop`도 들어 있다.

```
┌──────┐
│상위 A├────┐   ← 상위 박스 세로변, drop: BOM 윗변보다 위
└──────┘    ▼
━━━━━━━━━━━━━━━━━━━━  BOM 윗변 (drop 아래 끝이 닿는 선)
┃ no ┃ 품번 ┃ QT'Y ┃   ← 하위 BOM 세로선: 윗변 아래
```

| 후보 | 판단 |
|---|---|
| 윗변~아랫변 **높이 전체** 세로선만 | ✗ 수량 열 사이 선이 빠짐 (샘플 20개: 윗변 아래 세로선 167개 중 67개가 한 행 아래에서 시작) |
| **위 끝이 윗변 이상(아래쪽)** 세로선 | ✓ drop·상위 박스는 빠지고, 수량 열 선은 남음 |

**결정: 위 끝 y ≥ BOM 윗변 y, 아래 끝 y ≤ 아랫변 y인 세로선의 x** (PDF 좌표는 y가 아래로 커짐).

## 3. 병합된 칸
case_0001 머리글: `QT'Y`가 수량 3열을 합친 한 칸 (엑셀 셀 병합). 수량 열 사이 세로선(x 755.5, 783.8)은 머리글 아래(y 191.3 = 윗변 171.5 + 한 행 19.8)에서 시작.

**결정: 모든 경계로 바둑판을 만들고, 행 가운데 높이에 세로선이 없으면 옆 칸과 병합** (`Cell.col_span`).
- 데이터 행은 수량 열이 다 살아 있어 3단계에서 열 번호를 바로 셈
- 머리글 OCR `QT'Y`는 병합 칸 하나에 들어감

## 확인된 사실
- 샘플 머리글은 1행 (820개 모두 `행 - 1 = num_items`, 실패 2개 제외)
- 두 줄 품명은 한 행 높이 안에 들어간다 (case_0001 12행 "BRKT-DIVE 3RD CUSH OTR, RH / (IMS)")
- 샘플 행 수 4~24, 취소 행 있는 도면 381개, 취소 비율 최대 50% (case_0001)
