# 12. 리비전 삼각형: 찾기 → 안의 숫자 읽기 → 붙이기

## 문제
행과 모부품에는 글자 외에 리비전 번호 `(02,01)`가 있다. 삼각형(△) 안의 숫자로 표시되며, 삼각형 선이 숫자와 붙어 있어 그대로는 글자 나누기가 깨진다.

**행 정보별 처리**
| 정보 | 방법 |
|---|---|
| 글자 (no, 품번, 품명, 수량) | 글자 읽기 4단계 + 모델 |
| `[DEL]` | 취소선 규칙 ([06](06_취소선.md)) |
| `(02,01)` | 이 문서 |
| `[BLUE]` | 출력 안 함 (PDF 글자는 검정, 파란 선 없음) |

**데이터 사실**
- 파랑(`0 0.314 1`)은 삼각형과 그 안 숫자뿐. 삼각형은 검정일 수도 있음
- 색 의미: 파랑 = 그 리비전에서 추가, 검정 = 그 리비전에서 삭제 (case_0002 3행 `(02,01)`: 파랑 △01 + 검정 △02)
- 여러 개면 json에서 항상 **큰 수 → 작은 수** (2개 394행, 3개 178행 전부)

**결정.** 색은 구분하지 않고 안의 숫자만 읽어 **내림차순**으로 출력한다.

---

## 1. 찾기
| 조건 | 걸러 내는 것 |
|---|---|
| 끝점이 맞물려 닫힌 세 선 | 삼각형이 아닌 것 |
| 세 변 길이가 같음 (피타고라스) | 다른 도형 |
| 밑변 수평 | 기울어진 도형 |
| 크기 = 변 ÷ 글자 높이 비율 | 글자 "4", "A"의 삼각형 부분 (글자 높이보다 작음) |
```
선 1: (362.6, 594.2) → (378.2, 594.2)    가로 15.6
선 2: (378.2, 594.2) → (370.4, 607.7)    √(7.8² + 13.5²) = 15.6
선 3: (370.4, 607.7) → (362.6, 594.2)    15.6
```
**크기 기준**
| 후보 | 문제 |
|---|---|
| 고정값 (변 ≈ 15.6) | 도면마다 크기가 다름 (PDF 103개, 삼각형 887개: 15.6 448개 / 20.3 114 / 23.4 103 / 24.9 44 / 17.2 26 …) |
| **글자 높이 대비 비율** | 한 도면 안에서 글자·삼각형이 같이 커지고 작아짐 |
- 모양은 전부 정삼각형 (변 차이 ≤ 0.1)
- case_0002: 변 15.6 / 안 숫자 높이 약 5 → 약 3배. 실제 비율 범위는 구현 때 여러 도면으로 확인

## 2. 읽기
```
삼각형 안쪽 범위의 선 → 삼각형 선 제거 → 나누기 → 정규화 → 래스터화 → 모델
```
- 취소선과 같은 이유로 삼각형 선을 지운다 (남기면 숫자와 이어짐)

## 3. 붙이기
**결정.** 같은 y에서 **오른쪽으로 가장 가까운 대상**에 붙인다
```
삼각형 → 모부품 박스면 → 그 박스의 rev
       → 표의 행이면   → 그 행 no에 (02,01)
```
```
모부품 쪽: 삼각형 오른쪽 끝 583 → 2 차이 → 모부품 박스 왼쪽 끝 585
행 쪽:     삼각형 오른쪽 끝 395 → 3 차이 → BOM 표 왼쪽 끝 398
```
- 어느 행/박스인지: 삼각형 y범위가 어느 **가로선 사이**에 들어가는지 (case_0002: 삼각형 y 594.2~607.7 → 표 가로선 591.0~610.9 사이)
- 박스·표 위치는 표 찾기에서 이미 구했으므로 비교만 한다. 모부품/자부품 구분은 붙는 대상이 정해 주므로 별도 단계 불필요
- "가장 가까운"을 쓰는 이유: 같은 y에 박스와 행이 둘 다 있는 도면 대비
- 확인: case_0002 박스 3개에 삼각형 2/2/1개 → json `(03,02)`/`(03,02)`/`(04)`와 일치

## 전체 흐름
```
① 찾기: 닫힌 세 선 + 정삼각형 + 밑변 수평 + 크기(글자 높이 대비 비율)
② 읽기: 삼각형 안쪽 선 → 삼각형 선 제거 → 글자 읽기 4단계 + 모델
③ 붙이기: 같은 y에서 오른쪽으로 가장 가까운 대상(박스 또는 행)
④ 출력: 숫자 내림차순 → "(02,01)"
```

## 구현 확인 (4-2, `bom/revisions.py`)
**크기.** 변 ÷ 글자 높이 = 샘플 전부 2.4, 테스트 2.16~3.58 → 범위 1.8~4.0

**붙이기: 여러 개면 왼쪽으로 줄지어 붙는다.**
```
△07 △04 △01 | 3      (22000 NO 3 행, 표에 닿는 건 △01뿐)
```
| 후보 | 문제 |
|---|---|
| 표에서 거리를 넓힘 | 테스트 도면엔 그림 속 삼각형이 많음 (22000 852개) |
| **이미 붙은 삼각형도 붙일 대상** | 없음. 오른쪽 삼각형부터 차례로 |
- 간격: 붙은 것 -0.6~5.8, 떨어진 것 31.6 이상 → 허용 = 글자 높이 × (-0.1 ~ 1.0)
- 행은 삼각형 가운데 y로 (상위 박스 행보다 삼각형이 큰 도면 있음)

**읽기: OCR 대신 글자 사전 ([06](06_취소선.md)).**
| 후보 | 장점 | 단점 |
|---|---|---|
| **사전** | 4-2에서 rev까지 끝나고 json과 바로 비교 | 안 숫자가 행 글자보다 작음 |
| 5단계 OCR | 글자 읽기가 한 곳 | 4-2는 개수만 확인 |
- 결정: 사전. 크기는 안 숫자 자신의 높이로 맞춤. 안 맞으면 검수 → 5단계 OCR
- 결과: 테스트 6개 전부 읽음 (88500은 한 자리 `7`·`1`·`8`), 샘플 817/818 = json, 0797은 삼각형 위에 글자가 겹친 결함 → 검수
