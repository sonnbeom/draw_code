## 샘플과 테스트 도면의 성격 (사용자 확인, 2026-11-23)
| | 샘플 820개 | 테스트 도면 6개 |
|---|---|---|
| 출처 | 팀원이 AI로 생성 (BOM 위치·행 수 등을 변수로) | 실제 엔지니어가 그린 도면 |
| 선 | 깔끔함, 사람이 "덜 그린" 곳 없음 | 화살표 틈·기울어진 선 등 오차 있음 |
| 쓰임 | **규칙이 맞나** 확인 (행 수, 연결 순서, 정답 json 비교) | **오차를 얼마나 봐줘야 하나** 결정 |

- 지금까지 오차 문제(화살촉 틈 8.5, 3° 기울기, 88500 화살표 틈 2.88)는 전부 테스트 도면에서 나옴 ([트러블슈팅 04](../트러블슈팅/04_화살촉_틈.md)·[05](../트러블슈팅/05_기울어진_연결선.md)·[08](../트러블슈팅/08_상위가_표인_도면.md))
- 샘플엔 생성기 결함도 있음 ([트러블슈팅 07](../트러블슈팅/07_BOM이_아래_표와_겹침.md))
- 실제 도면이 6개뿐이라 못 본 오차가 있을 수 있다. 실제 도면을 더 얻는 것이 오차 기준 확인에 가장 도움이 됨

## xlsx 구조
| 행 | 내용 |
|---|---|
| 1행 | `NO \| PART NO \| PART NAME \| [1] 32100-TMC00A (03) \| ...` (모부품 번호·품번·rev) |
| 2행 | 모부품 이름 |
| 3행~ | 부품 행 (번호, 품번, 품명, 모부품별 수량) |

- 표시: `13 (04) [DEL]` = 취소선 + rev 04 / `[BLUE]` = 파란 행 / `(02,01)` = 삼각형 2개

## PDF 구성
- 부품표(BOM), 그 위에 쌓인 **모부품 박스**, 박스에서 수량 열로 내려오는 **화살표 연결선**
- 삼각형(△) 안의 숫자 = rev

## 변형 요소
| 요소 | 범위 |
|---|---|
| 헤더 양식 | standard / slash_pno (I/NO, P/NO) / slash_qty_assy (대각선 Q'TY·ASS'Y) |
| 모부품 수 | 1~8개 |
| 부품 행 수 | 4~24행, 품명이 두 줄인 경우 있음 |
| 페이지 크기 | 30종 (A3 1190×842 ~ 초광폭 11905×2384). case_0306은 긴 도면 구석에 표가 작게 있음 |

## 색
| 색 값 | 쓰임 |
|---|---|
| `0 0 0` 검정 | 대부분의 선, 글자 (BLUE 행 글자 포함) |
| `0 0.314 1` 파랑 | rev 삼각형과 그 안 숫자만 |
| `0 0.353 0.706` | 로고, 치수선 |

## 테스트 도면 (`C:\draw_code_test_data\draw`, 6개)
실제 입력 형식(DAS, CATIA 출력). 정답 없음. 샘플과 **같은 폰트** (사용자 확인, 좌표 비교는 안 함).

| 파일 (품번) | 크기 | BOM 모양 |
|---|---|---|
| 22000-USTA0 | 7738×2384 | 상위 박스 1개, 29행 |
| 28440-LX3840 | 3370×2384 | 상위 박스 2개, 머리글 `NO / P/NO / P/NAME / Q'TY` |
| 88300-NQ6A20 | 4762×2384 | 상위 박스 1개 |
| 88361-NX560 | 2384×1684, 2쪽 | 상위 박스 4개 (2쪽은 선 77개뿐) |
| 88400-NX530 | 4762×2384 | 상위 박스 8개, `5-1` 같은 가지 번호 |
| 88500-NR050 | 11905×2384 | **상위가 표** (25행), 하위 표 38행 × 수량 25열 |

**샘플과 다른 점**
- 글자는 전부 선 획. 텍스트 객체는 4개 파일에 승인 도장 날짜 하나씩뿐 (굴림체, `2026-09-08`, `2026/07/30` 등 형식 섞임) + 이미지 객체 1개씩
- 열 구성이 도면마다 다름. 88500 하위 표: `I/NO | PART NO | PART NAME | MATERIAL | QTY` (MATERIAL 추가, 값 `ASSY`, `SCM435MS`, `SWCH10A`). 88500 상위 표: `I/NO | PART NO | PART NAME | NOTE`
- 88500 파랑은 `(0, 0, 1)`이고 **행 글자 전체가 파랑** (34~37행). 샘플은 `0 0.314 1`이고 BLUE 행 글자도 검정
- 수량 칸 하나에만 걸친 **짧은 취소선** (88500 12열, 23열의 `1`, `4`)
- 한 칸에 두 줄: 22000 2행 품번 `22100-USTA0`(취소) + `22100-USTC0`, 1행 수량 `2`(취소) + `1`
- 품명 넘침: 88500 4행 `…+USB2` 뒤의 `)`가 셋째 줄로
- 표제란 `MATERIAL / P/NAME / P/NO`에 상위 품번 목록이 또 있음 (88361, 88400)
