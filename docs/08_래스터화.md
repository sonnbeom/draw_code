# 08. 래스터화: 모델 입력 만들기

## 문제
선 하나 = 숫자 4개 (x1, y1, x2, y2). '1'은 선 1개(숫자 4개), '8'은 20개(숫자 80개) → 글자마다 **입력 개수가 다르다.** 모델은 칸 수가 정해진 신청서와 같아서 항상 같은 개수를 받아야 한다.

## 결정. 고정 크기 격자에 칠한다
- 정규화한 글자를 모눈종이 위에 그린다. 선이 지나간 칸 = 1, 아닌 칸 = 0
- 선이 몇 개든 칸 수는 그대로 → 16×16이면 **항상 256개**
```
'1' →  0 1 0 0
       0 1 0 0      (4×4 예시: 16개)
       0 1 0 0
       0 1 0 0
```

## 격자 크기
| 격자 | 트레이드오프 |
|---|---|
| 4×4 | 너무 거침. '8'이 꽉 찬 네모, "0"과 "O"가 같아짐 |
| **16×16** | 구분에 충분, 입력 수 적당 |
| 64×64 | 입력이 너무 많고 미세한 차이에 과민 |

- 격자 크기처럼 사람이 미리 정하고 실험으로 조정하는 값 = **하이퍼파라미터** (선 길이 기준, 허용 오차 등도 해당)
- 도면 전체가 아니라 **글자 하나만** 정규화해서 그리므로 해상도 문제가 없다
