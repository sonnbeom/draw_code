# 7. 래스터화: 모델 입력 만들기 (Q18~19)

> 앞 단계와의 연결: 정규화로 위치·크기를 맞췄다 → 그런데 글자마다 선 개수가 다르다.

## Q18~19. 선 개수가 글자마다 다르다

'1'은 1개, '8'은 20개. 모델은 입력 개수가 고정이어야 하는데?

**내 답.**
- (처음) 무엇을 묻는지 모르겠다. 입력이 같아야 하는데 매번 달라서 문제라는 거지?
- (다음) 선이 20개가 넘으면 4×4에 들어갈 수는 있는 거야?
- (다음) 4단계까지 온 건 이해가 되는데, 이게 선이 여러 개인 거랑 무슨 상관이지? 입력 개수랑 무슨 상관이지?
- (마지막) 아, 그냥 애초에 16×16으로 정하고 그 사이에 데이터를 채워서 한다는 거구나

> 막혔던 지점: 모눈종이가 왜 갑자기 나오는지, 입력 개수와 무슨 상관인지.
> 풀린 계기: "선 그대로 = 선마다 숫자 4개라 개수가 변함" vs "모눈종이 = 칸 수 고정"을 나란히 비교한 것.

**정리.**
- 선 하나 = 숫자 4개 (x1, y1, x2, y2). 그대로 주면 '1'은 4개, '8'은 80개 → **개수가 달라진다**
- 모델은 **칸 수가 정해진 신청서**와 같다. 16칸짜리 모델은 항상 숫자 16개만 받는다.
- 해결: **모눈종이(격자) 크기를 미리 고정**하고, 정규화한 글자를 그 위에 그린다
  - 선이 지나간 칸 = 1, 안 지나간 칸 = 0
  - 선이 몇 개든 칸 수는 그대로 → 16×16이면 **항상 256개**
  ```
  '1' →  0 1 0 0
         0 1 0 0      (4×4 예시: 16개)
         0 1 0 0
         0 1 0 0
  ```
- 4×4는 너무 거칠다 ('8'이 꽉 찬 네모가 됨) → 보통 16×16 ~ 32×32
- 사람이 미리 정하고 실험하면서 조정하는 값 = **하이퍼파라미터** (격자 크기, 선 길이 기준, 허용 오차 등)
- 도면 전체가 아니라 **글자 하나만** 정규화한 뒤에 이미지로 만들기 때문에 해상도 문제가 없다
